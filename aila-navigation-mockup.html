This mockup keeps the existing top-level navigation visible, while making search, Help Center, Shop, and account access easier to scan before users choose a primary section.

Design notes

  • Navigation labels are compact and kept on one row.
  • Search is promoted from an icon to a small search field.
  • Help Center and AILA Shop use white utility icons with hover text.
  • Hello, Molly opens a structured My AILA dropdown.
  • The hamburger menu is removed from the desktop header.
